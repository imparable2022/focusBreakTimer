Cambios

0.4.0 - inicio automático y horario de suspensión

  • Nueva opción para iniciar el temporizador al iniciar NVDA, desactivada por defecto.
  • Nuevo horario de suspensión opcional, desactivado por defecto, con 22:00 → 06:00 como valores iniciales.
  • Se admiten horarios que cruzan medianoche.
  • Al entrar en la franja, el ciclo se pausa y se libera de forma segura cualquier bloqueo de Input Lock iniciado por el temporizador.
  • Al salir de la franja se reanuda el mismo punto del ciclo.
  • Si NVDA arranca dentro del horario con inicio automático activado, el inicio se difiere hasta la hora de reanudación.

0.3.2 - anuncios automáticos configurables

  • Nueva casilla para anunciar automáticamente el tiempo restante, desactivada por defecto.
  • El intervalo entre anuncios ahora se muestra en minutos; 5 minutos por defecto.
  • El control del intervalo queda deshabilitado cuando los anuncios automáticos están desactivados.
  • Se conserva compatibilidad con los valores en segundos guardados por versiones anteriores.
  • El comando NVDA+Alt+E, T sigue informando el tiempo bajo demanda.

0.3.1 - iniciar y reiniciar separados

  • I inicia el temporizador.
  • Shift+I reinicia el temporizador desde el comienzo.
  • I ya no reinicia accidentalmente una ejecución activa; NVDA indica que se use Shift+I.

0.3.0 - capa de comandos

  • NVDA+Alt+E activa la capa del temporizador.
  • I inicia o reinicia; D detiene; T informa tiempo y estado; R alterna repetición; O abre directamente las opciones del complemento.
  • La capa sale después de cada orden y emite un tono ante una tecla desconocida.
  • R conserva el último número finito de ciclos y modifica también una ejecución activa.
  • La apertura directa de opciones usa la API pública actual popupSettingsDialog.
  • Pruebas automatizadas ampliadas para la capa y el cambio de repetición durante la ejecución.

0.2.0 - configuración completa en Opciones de NVDA

  • Categoría propia Temporizador de enfoque en Preferencias, Opciones.
  • Duración del enfoque y del descanso configurables en minutos.
  • Casilla para repetir los ciclos indefinidamente y control para indicar un número finito de ciclos.
  • Casilla para activar o desactivar Input Lock durante el descanso.
  • Se mantienen configurables los anuncios periódicos y los sonidos.
  • Valores predeterminados: 30 minutos de enfoque, 5 minutos de descanso y repetición indefinida.

0.1.0 - compilación de prueba

  • Primera conversión del script independiente a Global Plugin de NVDA.
  • Motor de enfoque/descanso independiente de NVDA y probado unitariamente.
  • Integración opcional y segura con Input Lock.
  • Planificación con core.callLater, sin consola ni proceso Python externo.
