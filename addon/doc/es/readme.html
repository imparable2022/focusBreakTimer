Temporizador de enfoque y descanso

Complemento global de NVDA basado en un temporizador de enfoque/descanso. Por defecto utiliza 30 minutos de enfoque y 5 minutos de descanso.

Uso

Los comandos no traen gestos predeterminados para evitar colisiones con la configuración de cada usuario. Abra NVDA, Preferencias, Gestos de entrada y busque la categoría Temporizador de enfoque. Allí puede asignar teclas a:

  • Inicia o reinicia el temporizador de enfoque.
  • Pausa o reanuda el temporizador de enfoque.
  • Detiene el temporizador de enfoque.
  • Informa el estado y el tiempo restante del temporizador.

Configuración

En Preferencias, Opciones, Temporizador de enfoque aparece una categoría propia del complemento. Allí se puede configurar:

  • Duración del enfoque, en minutos.
  • Duración del descanso, en minutos.
  • Repetir los ciclos indefinidamente.
  • Número de ciclos cuando la repetición indefinida está desactivada.
  • Activar Input Lock durante el descanso.
  • Intervalo de anuncios del tiempo restante.
  • Reproducir sonidos al cambiar de período.

Los valores predeterminados son 30 minutos de enfoque, 5 minutos de descanso y repetición indefinida. Los cambios se guardan en la configuración de NVDA y se aplican al iniciar o reiniciar el temporizador.

Integración con Input Lock

Para bloquear la entrada durante el descanso se requiere el complemento Input Lock. Su comando “Toggle input lock” debe tener un gesto de teclado asignado. El temporizador detecta ese gesto y usa el propio complemento Input Lock, sin simular una combinación fija de Windows.

El temporizador sólo intenta desactivar un bloqueo que él mismo haya iniciado. Si el usuario desbloquea manualmente durante un descanso, el temporizador abandona la propiedad del bloqueo y no vuelve a alternarlo al finalizar ese descanso.

Notas

Si Input Lock no está instalado, no está cargado o no tiene un gesto de teclado asignado, el temporizador continúa funcionando y anuncia el descanso, pero no bloquea la entrada.
