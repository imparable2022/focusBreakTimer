Temporizador de enfoque y descanso

Complemento global de NVDA basado en un temporizador de enfoque/descanso. Por defecto utiliza 30 minutos de enfoque, 5 minutos de descanso y repetición indefinida.

Capa de comandos

Pulse NVDA+Alt+E y luego una tecla:

  • I: iniciar el temporizador.
  • Shift+I: reiniciar el temporizador desde el comienzo.
  • D: detener el temporizador.
  • T: informar la fase, el ciclo y el tiempo restante.
  • R: activar o desactivar la repetición indefinida.
  • O: abrir directamente las opciones del Temporizador de enfoque.

La capa se cierra después de cada comando. Una tecla desconocida produce un tono de error y también cierra la capa.

Al desactivar la repetición con R se utiliza el último número finito de ciclos configurado, 4 por defecto. El cambio se aplica también a una ejecución que ya esté en marcha.

Configuración

En Preferencias, Opciones, Temporizador de enfoque aparece una categoría propia del complemento. Allí se puede configurar:

  • Duración del enfoque, en minutos.
  • Duración del descanso, en minutos.
  • Repetir los ciclos indefinidamente.
  • Número de ciclos cuando la repetición indefinida está desactivada.
  • Activar Input Lock durante el descanso.
  • Intervalo de anuncios del tiempo restante.
  • Reproducir sonidos al cambiar de período.

Los cambios realizados en el panel se aplican al iniciar o reiniciar el temporizador.

Integración con Input Lock

Para bloquear la entrada durante el descanso se requiere el complemento Input Lock. Su comando “Toggle input lock” debe tener un gesto de teclado asignado. El temporizador detecta ese gesto y usa el propio complemento Input Lock, sin simular una combinación fija de Windows.

El temporizador sólo intenta desactivar un bloqueo que él mismo haya iniciado. Si el usuario desbloquea manualmente durante un descanso, el temporizador abandona la propiedad del bloqueo y no vuelve a alternarlo al finalizar ese descanso.

Nota sobre NVDA+Alt+E

El gesto puede coincidir con otros complementos. Si existe una colisión en su instalación, remapee uno de los comandos desde Gestos de entrada.
